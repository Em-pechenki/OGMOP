name: Git Workflow
description: Правила git: ветки, коммиты, пуш, откат, частота обновлений GitHub.
---

## Ветки
- `main` — продакшен, GitHub Pages.
- Фичи: `feat/<name>`, фиксы: `fix/<name>`.

## Коммиты
- Частые (каждые 5-15 мин или после задачи).
- Формат: `type(scope): message` (feat, fix, docs, chore, test).
- Один коммит = одна логическая задача.

## Пуш
- После каждого коммита — push на origin main (или PR).
- GitHub Pages обновляется автоматически.

## Откат
- `git revert <commit>` для отката конкретного изменения.
- `git reset --hard <tag>` для отката к версии.
- Теги: `v0.1.0`, `v0.2.0`.

## Правила
- Никогда не коммить секреты.
- Перед push — pull --rebase.
- Конфликты решает командир.
