## Принципы параллелизма
1. Декомпозируй задачу на независимые атомарные единицы.
2. Каждая единица = отдельный агент.
3. Агенты работают в изолированных зонах (файлы/модули).
4. Запускай через subagent параллельно (Promise.all).
5. Собирай отчёты по завершении.

## Избежание конфликтов
- Один файл — один агент.
- Shared-ресурсы (типы, конфиги) — через командира.
- Если конфликт — командир разрешает, эскалирует директору.

## Масштабирование
- Директор запускает командиров параллельно.
- Командир запускает рабочих параллельно.
- Глубина: директор -> командир -> рабочий (3 уровня).
- Можно запускать десятки/сотни рабочих одновременно.

## Отчётность
- Каждый агент отчитывается: что сделал, какие файлы, результат.
- Командир агрегирует отчёты.
- Директор информирует заказчика.
