## Хакатон
- Длительность: 48 часов.
- Команда: сотни AI-агентов под управлением директора.
- Заказчик общается с директором.

## Приоритеты
1. Рабочий прототип на GitHub Pages (первые часы).
2. Основной функционал.
3. Полировка UI/UX.
4. Тесты и документация.

## Стек
- Frontend: React + Vite + TypeScript + TailwindCSS.
- Backend: Node.js + Express (или serverless).
- Deploy: GitHub Pages (статика), GitHub Actions.
- Данные: localStorage / mock / Firebase (если нужно).

## Ограничения
- GitHub Pages — только статика. Бэкенд — либо serverless (Vercel/Render), либо mock на фронте.
- Не переусложнять: сначала работает, потом красиво.
- Частые коммиты и деплои для демонстрации прогресса.
