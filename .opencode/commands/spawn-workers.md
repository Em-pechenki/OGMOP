1. Определи список независимых задач из текущего плана.
2. Для каждой задачи запусти подходящего рабочего (worker-coder/tester/docs/devops) через соответствующего командира.
3. Запускай параллельно (Promise.all).
4. Собери отчёты и отчитайся.
