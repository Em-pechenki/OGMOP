# OGMOP — Hackathon Project

## Миссия
Проект разрабатывается командой из сотен AI-агентов под управлением ДИРЕКТОРА.
Цель: максимальная скорость разработки при минимальных конфликтах между агентами.

## Иерархия агентов
1. **ДИРЕКТОР** (primary) — общается с заказчиком, декомпозирует задачи, распределяет между командирами, контролирует.
2. **КОМАНДИР** (subagent) — специализация: backend / frontend / devops / qa / docs / data / security / mobile. Раздаёт задачи рабочим, проверяет результат.
3. **РАБОЧИЙ** (subagent) — выполняет конкретную атомарную задачу (пишет код, тесты, документацию).

## Правила параллельной работы
- Каждый агент работает только в своей зоне ответственности (каталоге/модуле).
- Задачи декомпозируются до атомарных единиц (один файл/функция/компонент).
- Перед редактированием файла агент проверяет, не занят ли он другим агентом (git status).
- Конфликты разрешаются командиром соответствующей специализации.
- Каждое изменение сопровождается коммитом с понятным сообщением.

## Git-воркфлоу
- Основная ветка: `main`.
- Частые коммиты и пуш на GitHub (каждые 5–15 минут или после завершения задачи).
- Теги версий: `v0.1.0`, `v0.2.0` и т.д.
- GitHub Pages обновляется автоматически через GitHub Actions при push в main.

## Структура проекта
- `src/frontend/` — фронтенд (React + Vite + TypeScript)
- `src/backend/` — бэкенд (Node.js + Express/Fastify)
- `src/shared/` — общие типы и утилиты
- `public/` — статические ассеты
- `tests/` — тесты
- `docs/` — документация
- `scripts/` — скрипты автоматизации

## Команды
- `/status` — статус проекта и прогресса
- `/deploy` — принудительный деплой
- `/commit-all` — закоммитить все изменения
- `/sync-github` — синхронизировать с GitHub
- `/spawn-workers` — запустить пул рабочих агентов

## Приоритеты (хакатон 48ч)
1. Рабочий прототип на GitHub Pages
2. Основной функционал
3. Полировка UI/UX
4. Тесты и документация

## Важно
- Никогда не коммить секреты (.env, ключи).
- Все изменения через git, чтобы можно было откатиться.
- Директор общается с заказчиком на русском.
