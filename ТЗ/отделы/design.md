# ТЗ — Отдел Дизайна (UI/UX)

## Миссия
Создать визуальный язык и UX-потоки проекта, чтобы фронтенд-команда могла реализовывать компоненты без догадок.

## Зона ответственности
- Цветовая палитра, типографика, сетка, отступы.
- Компоненты дизайн-системы (Button, Input, Card, Modal, Toast, Navbar, Footer).
- Макеты страниц (wireframes + high-fidelity) в Figma или текстовом описании.
- Иконки, иллюстрации, логотип.
- Адаптивность (mobile-first): 320/768/1024/1280/1536.
- Тёмная/светлая тема (если требуется по ТЗ).

## Артефакты (deliverables)
1. `docs/design/tokens.md` — дизайн-токены (цвета, шрифты, радиусы, тени).
2. `docs/design/components.md` — спецификация каждого компонента (состояния, варианты, размеры).
3. `docs/design/pages.md` — описание страниц и их структуры.
4. `public/` — ассеты (логотип, иконки, favicon).
5. `src/frontend/styles/` — CSS-переменные/ Tailwind theme.

## Задачи по фазам

### Фаза 0 (0–2 ч)
- [ ] Прочитать ТЗ, выделить ключевые экраны и пользовательские потоки.
- [ ] Создать moodboard (3–5 референсов).
- [ ] Определить палитру (primary, secondary, accent, neutral, success/warning/error).
- [ ] Выбрать шрифты (heading + body).

### Фаза 1 (2–8 ч)
- [ ] Дизайн-токены → `docs/design/tokens.md` + Tailwind config.
- [ ] Компоненты (атомарные): Button, Input, Textarea, Select, Checkbox, Radio, Switch.
- [ ] Компоненты (молекулы): Card, Modal, Toast, Dropdown, Tooltip, Badge, Avatar.
- [ ] Layout: Header, Footer, Sidebar, Container, Grid.
- [ ] Главная страница (wireframe → high-fidelity).
- [ ] Favicon и логотип.

### Фаза 2 (8–16 ч)
- [ ] Макеты всех страниц из ТЗ (по приоритету P0 → P1).
- [ ] Состояния: empty, loading, error, success.
- [ ] Адаптивные варианты для каждой страницы.
- [ ] Анимации/микроинтеракции (hover, focus, transitions).

### Фаза 3 (16–22 ч)
- [ ] Полировка: выравнивание, контраст (WCAG AA), доступность.
- [ ] Тёмная тема (если требуется).
- [ ] Финальная проверка всех экранов.

### Фаза 4–5 (22–30 ч)
- [ ] Поддержка: исправление визуальных багов по фидбеку QA/заказчика.
- [ ] Подготовка скриншотов для демо.

## Критерии приёмки
- Все компоненты имеют состояния hover/focus/active/disabled.
- Контраст текста ≥ 4.5:1 (WCAG AA).
- Адаптивность проверена на 320/768/1024/1280.
- Дизайн-токены синхронизированы с Tailwind config.
- Нет «магических» цветов/размеров вне токенов.

## Зависимости
- Зависит от: ТЗ (экраны, требования).
- Блокирует: FE (компоненты), DOCS (скриншоты).

## Инструменты
- Figma (если доступен) или текстовые спецификации.
- Tailwind CSS, CSS variables.

## Правила
- Не пишет код — только спецификации и ассеты.
- Каждый компонент описывается: варианты, размеры, состояния, поведение.
- Изменения в токенах — через DATA/FE командира (синхронизация).
