# Техническое задание (ТЗ)

Положите сюда файл(ы) с описанием проекта: требования, функционал, дизайн, дедлайны.
Агенты автоматически прочитают содержимое этой папки при запуске.

## Рекомендуемая структура ТЗ
1. Название и цель проекта
2. Целевая аудитория
3. Основной функционал (user stories)
4. Дополнительный функционал
5. Технические требования (стек, API, БД)
6. Дизайн/UX (макеты, референсы)
7. Критерии приёмки
8. Дедлайн и приоритеты

Поддерживаемые форматы: .md, .txt, .pdf, .docx, .png/.jpg (скриншоты).
