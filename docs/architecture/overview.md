# Архитектура OGMOP

## Обзор
Веб-приложение (React + Vite) на GitHub Pages. Бэкенд (Node/Express) опционально.

## Агенты
- Директор -> Командиры -> Рабочие.
- Параллельная разработка через изоляцию по файлам/модулям.

## Деплой
- GitHub Actions: build Vite -> upload artifact -> deploy-pages.
- URL: https://Em-pechenki.github.io/OGMOP/
