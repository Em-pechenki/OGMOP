# Безопасность — OGMOP

Статус: в разработке (Фаза 0–1).

- Модель угроз: планируется (SEC-трек).
- CORS/Helmet/rate-limit: планируются.
- Валидация входных данных: Zod (планируется).
- Хранение секретов: шифрование/маскирование (цель).
- Сканирование только тестового/учебного репозитория (ограничение ТЗ).
