## Типографика

- **Heading**: Inter / system-ui, 600–700 weight.
- **Body**: Inter / system-ui, 400 weight.
- **Mono**: JetBrains Mono / Consolas (для кода).

## Отступы и радиусы

- Радиус карточек: `8px`–`12px`.
- Радиус кнопок: `8px`.
- Базовый отступ: `8px` (кратные 8).

## Тени

- Карточки: `0 0 24px rgba(0,0,0,0.03)` (как на сайте).
- Hover: `0 4px 12px rgba(0,0,0,0.08)`.

## Иконки

- Зелёный вектор (green-vector.svg) — фирменный знак.
- Иконки: линейные, тонкие, цвет #494B52.
