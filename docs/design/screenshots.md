## 2. Правила съёмки
- Тема: светлая (по умолчанию), шрифт Inter.
- Данные: демо-репозиторий (32 находки) для реалистичности.
- Скрыть dev-панели, консоль, курсор (опц.).
- Имя файла: `{nn}-{slug}.png`, без пробелов.
- Формат: PNG, оптимизированный (≤ 500KB). WebP-копия для Pages.
- Хранить оригинал + оптимизированную версию.

## 3. Состав кадра (детали)

### 01-home (лендинг)
- Hero: заголовок «Безопасность кода — визуально и просто», подзаголовок, CTA «Открыть редактор» + «Шаблоны», мокап редактора справа.
- Полоса метрик: 3 сканера / 32 находки / AI / CI/CD.
- 3 карточки Features видны частично.
- Тема светлая, шрифт Inter.

### 03-editor-graph
- Ноды: Trigger → Secrets Scanner → SCA Scanner → SAST Scanner → AI → Notify.
- Стрелки smoothstep, цвет `--color-border-strong`.
- Properties panel открыт на Scanner (Params tab).

### 04-run-execution
- 2 ноды success, 1 running (pulse), остальные idle.
- Анимированные рёбра (flow).
- Timeline справа с текущим шагом.

### 05-run-results
- Findings отсортированы critical→info, 3-4 карточки видны.
- AI-отчёт развёрнут.

## 4. Инструменты
- Локально: `npm run dev` + `npm run server`, скриншот через браузер (Ctrl+Shift+S) или расширение.
- Автоматизация (опц.): Playwright/Puppeteer не в зависимостях; добавлять не требуется для MVP.
- Для GitHub Pages: положить в `public/demo/` и ссылаться `/demo/01-home.png`.

## 7. Мокапы (описание) для демо

Назначение: описания мокап-экранов для подготовки иллюстраций (AI-генерация или ручная отрисовка) до съёмки реальных скриншотов. Хранить в `docs/screenshots/mock/` с суффиксом `-mock`.

### M1. Лендинг (hero + features)
- Описание: светлая страница, верхняя навигация с логотипом Центр-инвест, hero с заголовком, подзаголовком, двумя зелёными/серыми кнопками и мокапом редактора справа (граф из 4 нод). Ниже полоса метрик и 3 карточки возможностей.
- Стиль: Inter, зелёный акцент #50B848, светло-серый фон секций, мягкие тени.
- Размер: 1280×800.

### M2. TemplateCard (default + featured)
- Описание: сетка 3 карточек шаблонов на светлом фоне: превью графа (миниатюра), название, описание 2 строки, теги (secrets/sca/sast), автор и дата, кнопки «Использовать»/«Копировать»/«Подробнее». Одна карточка featured с бейджем «Рекомендуемый» и рамкой primary.
- Стиль: карточки белые, radius 12px, тень мягкая, hover-подъём.
- Размер: 1280×800 (фрагмент сетки) или 480×320 (одна карточка).

### M3. Empty state шаблонов
- Описание: центрированный блок на светло-сером фоне: иконка logic (серая), заголовок «Шаблонов пока нет», описание, две кнопки «Опубликовать» (зелёная) и «Создать вручную» (серая).
- Размер: 1280×800.

### M4. Loading skeleton шаблонов
- Описание: сетка 6 карточек-заглушек (shimmer) на светлом фоне, без спиннера.
- Размер: 1280×800.

### M5. Error state шаблонов
- Описание: центрированный блок: красная иконка alert, заголовок «Не удалось загрузить шаблоны», сообщение, кнопка «Повторить».
- Размер: 1280×800.

### M6. Mobile landing (390×844)
- Описание: вертикальный стек: hero (заголовок, CTA, иллюстрация снизу), метрики 2×2, features 1 колонка.
- Размер: 390×844.

### Правила мокапов
- Помечать файлы суффиксом `-mock` (например `01-home-mock.png`).
- Не использовать в финальной презентации без замены на реальные скриншоты.
- Цвета и шрифты строго по токенам (см. `tokens.md`).
