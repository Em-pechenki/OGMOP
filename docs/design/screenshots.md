## 2. Правила съёмки
- Тема: светлая (по умолчанию), шрифт Inter.
- Данные: демо-репозиторий (32 находки) для реалистичности.
- Скрыть dev-панели, консоль, курсор (опц.).
- Имя файла: `{nn}-{slug}.png`, без пробелов.
- Формат: PNG, оптимизированный (≤ 500KB). WebP-копия для Pages.
- Хранить оригинал + оптимизированную версию.

## 3. Состав кадра (детали)

### 03-editor-graph
- Ноды: Trigger → Secrets Scanner → SCA Scanner → SAST Scanner → AI → Notify.
- Стрелки smoothstep, цвет `--color-border-strong`.
- Properties panel открыт на Scanner (Params tab).

### 04-run-execution
- 2 ноды success, 1 running (pulse), остальные idle.
- Анимированные рёбра (flow).
- Timeline справа с текущим шагом.

### 05-run-results
- Findings отсортированы critical→info, 3-4 карточки видны.
- AI-отчёт развёрнут.

## 4. Инструменты
- Локально: `npm run dev` + `npm run server`, скриншот через браузер (Ctrl+Shift+S) или расширение.
- Автоматизация (опц.): Playwright/Puppeteer не в зависимостях; добавлять не требуется для MVP.
- Для GitHub Pages: положить в `public/demo/` и ссылаться `/demo/01-home.png`.
