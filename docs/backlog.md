# Backlog — Cyber Garden 2026: AI Security Workflow

> Источник: `ТЗ/tz.md` (Cyber Garden 2026, AI Security Workflow).
> План: `docs/plan-30h.md`. ТЗ отделов: `ТЗ/отделы/*.md`.

## Эпики

1. **E1 Конструктор workflow** — drag-and-drop редактор нод (React Flow).
2. **E2 Ноды триггеров и логики** — запуск по кнопке/расписанию, if/else, сравнение, regex, уведомления.
3. **E3 Анализаторы безопасности** — секреты (regex), SCA (Gradle + CVE JSON), SAST (Kotlin/Spring Boot простые правила).
4. **E4 Классификация критичности** — уровни (critical/high/medium/low/info).
5. **E5 AI-анализ** — LLM агрегация, объяснение, рекомендации.
6. **E6 Визуализация выполнения** — статусы нод, данные между нодами, логи.
7. **E7 Тестовый репозиторий** — учебный Kotlin/Spring Boot/Gradle с секретами, уязвимыми deps, SAST-проблемами, JSON CVE.
8. **E8 Задачи со звёздочкой** — шаблоны, CI/CD интеграция, AI-генерация сценариев.
9. **E9 Презентация и демо** — демо-сценарий, слайды.
